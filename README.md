# KeebDeck Hexpansion

A keyboard hexpansion for the [Tildagon badge](https://tildagon.badge.emfcamp.org/) using the [solder.party KeebDeck Keyboard](https://www.solder.party/docs/keebdeck/keyboard/). Software for the hexpansion is [provided by @sodoku](https://github.com/sodoku/tildagon-keebdeck).

![KeepDeck Hexpansion V3 next to the Tildagon](/images/tildagon_keebdeck_v3.jpeg)

## Features

- Full layout keyboard
- RGB Backlit keys
- Type in text inputs
- Auto-installs driver when plugged in

Available for EMF 2026 camp ticket holders on the emfcamp website. See [here](https://blog.emfcamp.org/2026/05/28/tildagon-2026-spaceagon/) for more info
